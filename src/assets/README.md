# راهنمای assetها

همه‌ی فایل‌های تصویری بر اساس محل استفاده دسته‌بندی شده‌اند. فایل جدید را در نزدیک‌ترین پوشه‌ی کاربردی قرار بده و از گذاشتن تصویر در ریشه‌ی `assets` خودداری کن.

| پوشه | کاربرد |
| --- | --- |
| `about-traits/` | پنج تصویر ویژگی‌های About Me |
| `behance/` | کاور کیس‌استادی‌های Behance |
| `beyond-work/` | عکس شخصی و reference سکشن Beyond Work |
| `case-studies/` | hero، تصویر محتوا و iconهای صفحات پروژه |
| `cursors/` | cursorهای سفارشی شبیه Figma |
| `dock-icons/` | iconهای منوی شناور پایین |
| `figma-icons/` | iconهای عمومی رابط شبیه Figma و modal تماس |
| `hero-icons/` | تصویر و iconهای اختصاصی Hero |
| `media/` | Spotify، IMDb و پوستر چهار فیلم |
| `profile/` | عکس پروفایل، avatar و visual پروفایل |
| `projects/` | تصویرها و vectorهای عمومی کارت پروژه |
| `sidebar-icons/` | iconهای سایدبار چپ و راست |
| `tech-icons/` | لوگوهای My Tech Stack و ابزارهای AI |
| `work-icons/` | filter، grid/list toggle و favicon پروژه‌ها |

فایل‌های reference یا variant حذف نشده‌اند؛ حتی اگر فعلاً import نشده باشند، در پوشه‌ی مرتبط نگه‌داری می‌شوند تا منبع طراحی مشخص بماند.
